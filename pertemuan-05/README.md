# P5 - JavaScript Dasar, DOM, Event, dan Validasi Sisi Klien

## Deskripsi

Dokumentasi pengembangan halaman web P5 yang meliputi JavaScript, DOM, event listener, navigasi, dan validasi formulir sisi klien.

## Fitur dan Pengembangan

- Navigasi responsif: Menambahkan tombol hamburger dengan event klik, status buka/tutup, dan tautan ke bagian Beranda, Tentang, serta Kontak.
- Validasi formulir: Menambahkan validasi nama, email, nomor telepon, tanggal lahir, dan pilihan prediksi. Pesan hasil validasi ditampilkan pada halaman.

## Pengujian

- Navigasi: Menguji tombol menu pada tampilan mobile dan tautan ke bagian halaman. Menu dapat dibuka, ditutup, dan navigasi berhasil menuju bagian yang dipilih.
- Formulir: Menguji form kosong, isian tidak valid, isian valid, dan tombol reset. Isian tidak valid ditolak, isian valid menampilkan pesan berhasil divalidasi, dan reset menghapus pesan. Data tidak dikirim atau disimpan.

## Riwayat Pengembangan

- Perubahan P4: Memperbarui `style.css` dan `index.html`, serta menambahkan tombol hamburger.
- Perubahan P5: Menambahkan navigasi, validasi formulir, dan pesan hasil. Pengujian di browser berhasil; perubahan ini belum dibuat commit Git.
