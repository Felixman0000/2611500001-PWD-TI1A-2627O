1. Konsep Dasar Pemrograman Web
- Pemrograman web adalah proses membuat aplikasi atau halaman yang dapat diakses melalui browser menggunakan jaringan/internet.

2. Arsitektur Klien-Peladen (Client-Server)
- Client minta data, Server tinggal kasih data.
Contoh: Browser abis itu ke Server abis itu ke Browser lagi.

3. HTTP Request & Response
- Request = permintaan dari browser.
- Response = jawaban dari server.

4. HTML, CSS, JavaScript, PHP, MySQL
- HTML = bikin web lebih struktur 
- CSS = bikin web lebih bagus 
- JavaScript = bikin web lebih interaktif 
- PHP = berfokus pada kinerja server
- MySQL = untuk nyimpan data
